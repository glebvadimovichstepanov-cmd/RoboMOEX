# Корпоративные события и e-disclosure

Источник пользователя: https://www.e-disclosure.ru/portal/company.aspx?id=312.
ID подтверждён официальным сайтом Сургутнефтегаза. На текущей машине автоматический
запрос получает HTTP 403. Обход ограничения не реализован. Статус unavailable
сохраняется; ранее полученные данные не удаляются, полнота архива не заявляется.

`disclosure.py` извлекает ссылки только на официальном хосте, проверяет имя
эмитента и явное время публикации, сохраняет HTML/SHA256/observed_at, отделяет
исправленные версии. Первый загруженный исторический текст имеет флаг
historical_version_unverified: исходная версия публикации не доказана.
После первой версии изменение текста получает known_at=observed_at.
Распознавание наличия слова «дивиденды» — лишь классификация сообщения,
не подтверждение суммы, ex-date или даты выплаты.

Парсер допускает article:published_time или явно подписанную дату публикации.
Произвольная дата внутри текста не используется как known_at. При неизвестной
разметке HTML сохраняется для разбора, событие не попадает в проверенный feed.
Живой парсер ещё требует проверки на доступной HTML-выгрузке этого сайта.

```powershell
.\.venv\Scripts\python.exe -m robomoex.disclosure --import-html saved-event.html --url "https://www.e-disclosure.ru/portal/event.aspx?EventId=ACTUAL_ID"
```

Для бэктеста `research --events verified-events.json` принимает JSON-массив
проверенных записей. Пустой массив допустим, но не означает полное покрытие.

| Поле | Требование |
|---|---|
| event_id | Уникальный ID; конфликтующие ревизии надо разрешить до импорта |
| ticker | SNGS или * для общерыночного риска |
| event_type | DIVIDEND, SPLIT, REPORT, OPEC, SANCTIONS, TAX, GEOPOLITICS |
| known_at | Подтверждённый момент доступности информации, с UTC offset |
| effective_at | Проверенный момент действия; для DIVIDEND — ex-date, не record date |
| source_url | HTTPS-ссылка на публикацию |
| verified | JSON boolean true после проверки факта и дат |
| amount_rub | Для DIVIDEND: сумма на акцию, >=0 |
| payment_at | Для учёта DIVIDEND в бэктесте: проверенный момент выплаты, с timezone |
| split_ratio | Для SPLIT: новые акции / прежние акции, >0 |

Импорт событий не разрешает торговлю автоматически: полнота корпоративного
и новостного покрытия по-прежнему должна быть подтверждена отдельно.
Двухдневный фильтр использует две следующие торговые даты переданного расписания;
без двух дат использует два календарных дня. Для production нужен полный
официальный календарь будущих сессий, включая выходные торги.
