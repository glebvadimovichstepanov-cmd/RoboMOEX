## Команды

```powershell
.\.venv\Scripts\python.exe -m robomoex.instrument_info
.\.venv\Scripts\python.exe -m robomoex.cbr
.\.venv\Scripts\python.exe -m robomoex.disclosure
.\.venv\Scripts\python.exe -m robomoex.research --algopack-db results/algopack/cache.sqlite --ml --diagnostics --output results/research_audit
```

`research --refresh` также пытается обновить ЦБ и раскрытия, записывает статусы
в source_refresh.json. История AlgoPack по-прежнему обновляется отдельной командой
algopack_cache. Для проверенных корпоративных действий предусмотрен `--events`.
Отсутствие/неполнота события не превращается в LOW risk. Формат — EVENT_FEED.md.

## Ограничения методологии

Dividend receivable учитывается в капитале с ex-date, доступные деньги — с
payment_at. Дивиденды gross, без налогов; покупка на ex-date не даёт требования
по предыдущему периоду. Сплит пересчитывает количество, цену входа и стоп;
дробное требование и неоднозначные одновременные действия отвергаются.
Временная метка внутрибардового стопа обозначает границу бара, точное время
исполнения по daily OHLC неизвестно. Forced exits не моделируют очередь и
частичное исполнение на неликивидном рынке — это остаётся ограничением.
