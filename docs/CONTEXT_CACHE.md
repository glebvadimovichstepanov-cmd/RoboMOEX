# Кеш внешнего контекста

Команда `robomoex-context` поддерживает инкрементальный кеш дневных источников:

- `IMOEX` — рыночный режим;
- `RGBI` — облигационный/ставочный режим;
- `USD000UTSTOM` — USD/RUB;
- `CNYRUB_TOM` — CNY/RUB;
- `BRFOB` — доступный на MOEX прокси Brent;
- `RTSI`, `LKOH`, `ROSN`, `TATN`, `BANE`, `GAZP`, `NVTK` — рынок и нефтяные аналоги;
- календарь фондового рынка MOEX — допустимые торговые даты.

Дивидендные события SNGS обновляются отдельным кешем `dividends.json` из публичной таблицы StocksRU. На дату отсечки выставляется `event_risk=HIGH`; дата объявления не выдумывается, поэтому предварительный двухдневный запрет включится только после подключения announcement feed.

Пример первичной загрузки:

```sh
uv run --frozen robomoex-context --cache-dir results/context_cache --start 2025-01-01 --end 2026-09-08
```

Повторный запуск с тем же диапазоном не скачивает уже сохранённые даты. Если конец диапазона расширился, загружается только хвост; если начало расширилось — только недостающий префикс. Каждый JSON содержит стабильную идентичность источника, диапазон и SHA-256 контрольную сумму. Запись выполняется атомарно.

При недоступности календарного endpoint его нейтральный календарный контекст строится только по наблюдаемым торговым датам из рыночных рядов и сохраняется с тем же контролем целостности. Это явно не заменяет корпоративный event feed: `event_penalty` остаётся 1.0 до подключения источника корпоративных событий.
