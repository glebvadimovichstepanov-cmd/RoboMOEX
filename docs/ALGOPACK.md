# AlgoPack: интеграция и порядок работы

## Компоненты

`algopack.py` читает MOEX_API_TOKEN или MOEX_TOKEN_FILE (по умолчанию
`.secrets/moex.token`), отправляет Bearer только на HTTPS apim.moex.com/iss.
Редиректы запрещены; ключ не входит в URL, кеш и сообщения ошибок.
Дополнительный CA: MOEX_CA_FILE или `.secrets/moex-ca.pem`.
Проверка сертификата и имени хоста обязательна; системное хранилище не меняется.

`algopack_cache.py`: реестр eq/fx/fo/FUTOI и снимков. Запросы истории окнами
до семи дней, проверка INDEX/TOTAL, схемы, диапазона и повторных страниц.
У FUTOI start не сдвинул пробный ответ, поэтому запросы ограничены одним днём.
Для временных HTTP/транспортных ошибок предусмотрено до трёх попыток.

SQLite хранит успешные окна, SHA256, точные диапазоны покрытия, observed_at
и версии изменённых ответов. Ошибка страницы не помечает окно загруженным.
Дозагружаются пробелы, префикс и хвост; текущий и предыдущий дни обновляются.
`--refresh` повторно запрашивает историю, сохраняя прежние версии.
Историческая загрузка отражает текущую версию API, а не гарантированный архив
данных, известных участнику рынка в прошлом.

Снимки отделены от исторического покрытия. Выборка trades ограничена первым
ответом API, не объявляется полным тик-архивом. Ограничения торгов загружаются
с полной пагинацией; такой запрос может занять несколько минут.

`algopack_features.py` рассчитывает рублёвый оборот, дисбалансы сделок, стакана
и заявок, 95-й перцентиль спреда, концентрацию и количество аномалий.
Объёмы в лотах не считаются акциями. Наблюдение должно быть опубликовано до
конца дня, фактор доступен со следующего московского дня; as-of объединение
ограничивает возраст 36 часами. Дневной спред — прокси, не цена исполнения.

`research.py --algopack-db` подключает эти признаки и рублёвый оборот к проверке
ликвидности, экспортирует признаки и их хеш. Сводный microstructure_score
объясняется в сигнале; вес по умолчанию нулевой до проверки добавочного эффекта.
Расширенные метрики аналогов, валют, контрактов и FUTOI пока доступны в кеше,
а не включены произвольно в торговый score. Новости остаются UNKNOWN.

## Команды из корня проекта

```powershell
.\.venv\Scripts\python.exe -m robomoex.algopack

# Полная дозагрузка реестра с 2025 года; конец — текущая дата
.\.venv\Scripts\python.exe -m robomoex.algopack_cache --start 2025-01-01 --futures BRV6 SiU6

# Только SNGS и текущие снимки
.\.venv\Scripts\python.exe -m robomoex.algopack_cache --only eq.SNGS.tradestats eq.SNGS.obstats eq.SNGS.orderstats eq.SNGS.hi2 eq.SNGS.alerts --snapshots

# Проверка кеша без сети
.\.venv\Scripts\python.exe -m robomoex.algopack_cache --status

.\.venv\Scripts\python.exe -m robomoex.context --authenticated
.\.venv\Scripts\python.exe -m robomoex.research --algopack-db results/algopack/cache.sqlite --output results/research_algopack
```

BRV6/SiU6 — проверенные контракты на 8 сентября 2026. Для следующих экспираций
необходимо выбрать новые из справочника и передать их через `--futures`.
Это не автоматическая историческая склейка. Неизвестный `--only` отвергается.

## Проверка 8 сентября 2026

- 49 наборов, 500730 записей; расширенный запуск завершён без ошибок.
- SNGS: 95967 tradestats, 96033 obstats, 97426 orderstats, 5984 HI2, 2129 alerts.
- SNGS запрошен с января 2025, остальные наборы — с августа 2026.
- 546 дат дневных факторов, 492 строки исследовательского набора со спредом.
- Walk-forward: четыре окна, финальный holdout без сделок из-за защитных условий;
  доходность 0, Sharpe не определён. Эффективность стратегии не подтверждена.
- 85 тестов и Ruff пройдены: пагинация, атомарность окна, пустое покрытие,
  ревизии, checksum, causal as-of, свежесть, TLS и ограничение передачи ключа.

## Что осталось

1. Полный backfill остальных наборов с января 2025, аудит календарного покрытия,
   пересборка OHLCV по московским сессиям. Текущий снимок расписания не доказывает
   исторические часы торгов.
2. История параметров и экспираций, склейка фьючерсов без look-ahead. Текущий
   лот SNGS=100 внесён в дневной replay; изменения лота в истории не проверены.
3. Корпоративные/новостные события с временем публикации, подтверждённые дивиденды
   и денежные потоки, официальный адаптер ставки ЦБ, WTI/российская нефть.
4. Проверка добавочного эффекта новых факторов на последовательных train/test
   окнах с издержками и поправкой на множественные гипотезы.
5. ISS+ WebSocket: отдельная проверка учётных данных/прав, heartbeat,
   восстановление sequence gaps, snapshot/update/removal, длительный paper-run.
   REST JWT не выдаётся за проверенную авторизацию STOMP passport.

Реальная отправка заявок и постоянный фоновый сервис не включены.
