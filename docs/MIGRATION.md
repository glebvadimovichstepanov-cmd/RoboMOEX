# Происхождение и решения о переносе

Источник: `glebvadimovichstepanov-cmd/test_backtrader_moexalgo`, ветка `stub`,
commit `1726a3c93aed500e73517437e9fd5b6ac2ade899` от 2026-08-23.
RoboMOEX создан отдельно; никаких записей в исходный репозиторий не требуется.

## Основной продукт 0.1

Выбрана одна воспроизводимая long-only confluence-стратегия из
`run_strategy_v2.py`: дневной тренд EMA10/EMA32, волатильность относительно
медианы ATR на 1m/15m/дневной сессии, RSI с логикой OR, фильтр тела свечи,
SL/TP через ATR. Это осознанное сужение первой версии: одно ядро расчётов
проще проверить перед подключением брокера. Прибыльность не утверждается.

| Исходная часть | Решение в RoboMOEX |
|---|---|
| confluence в `run_strategy_v2.py` | Перенесена логика, переписаны индикаторы и выравнивание времени |
| vectorbt execution | Заменён небольшим явным long-only симулятором, без числовых direction enum |
| MoexAlgoStore / MoexAlgoData | Заменены контрактом OHLCV и read-only адаптером публичного MOEX ISS |
| Lag-Llama inference | Исправленный независимый контракт `future_forecast`; полноценный стек модели не переносится |
| `main.py`, brokerTbank live example | Не переносятся до реализации lifecycle заявок и risk gate |
| Backtrader, несколько CMV/MC стратегий | Не переносятся: не нужны выбранному релизу |
| AlgoPack Super Candles, логин/пароль MOEX | Не переносятся: основной стратегии достаточно OHLCV |
| LLM-комментарий через localhost | Не переносится: не влияет на детерминированный сигнал |
| Оптимизаторы по всей истории | Не переносятся; корректный walk-forward — последующий этап |
| CSV результатов, кэши, pyc, egg-info | Не переносятся |
| Конфиги с ключами/счетами | Не переносятся; v0.1 вообще не запрашивает торговые секреты |

Это функциональная миграция выбранного сценария, не fork всех экспериментов.
Результаты и параметры прежней оптимизации нельзя использовать как результаты
нового движка: изменились исполнения, ATR smoothing, прогрев и причинность.

## Исправления с изменением поведения

- `direction=1/2` больше не используется для кодирования buy/sell. Позиция —
  явный объект long-only с количеством и стоимостью; выход закрывает её.
- Выходы проверяются на каждом баре независимо от фильтров входа.
- Решение по close[i] исполняется не раньше open[i+1]. Условия high/low бара
  до момента входа не используются для создания сделки на этом же close.
- Старший бар становится доступен на его close_time. В начале дня доступна
  только предыдущая законченная дневная сессия.
- `bfill` удалён. До окончания прогрева — отсутствие сигнала, а не значения
  индикаторов из будущего.
- RSI корректно обрабатывает нулевые потери и плоскую цену. ATR использует
  абсолютные гэпы; выбран единый вариант EWM(alpha=1/14) с явным прогревом.
- Параметр doji_thresh реально используется вместо захардкоженного 0.3.
- Ошибки данных/пагинации не превращаются в «нет сделок».
- Drawdown — положительная доля от достигнутого пика с учётом начального
  капитала. Sharpe считается по дневным изменениям equity с оговорённой 252.
- Нет фиксированной END_DATE для текущего режима; paper получает UTC now
  и проверяет свежесть. Исторический cutoff задаётся только backtest.
- Прогноз использует полный контекст через predictor.predict, проверяет
  старт после последнего наблюдения. Квантили цен считаются после преобразования
  полных sample paths; не суммируются квантили отдельных доходностей.
- Нет глобального monkey patch torch.load и автоматической загрузки checkpoint.

## Зависимости

Runtime: numpy, pandas, tzdata и стандартная библиотека Python.
Полные транзитивные версии и хеши артефактов закреплены в uv.lock.
Dev-инструменты отделены через extra `dev`. Код сторонних библиотек не скопирован
в репозиторий. `LICENSE` сохраняет MIT notice исходной библиотеки.
